# amarAbroad logo: "Cloud buddy"

A friendly cloud (sky, travel) in a graduation cap (study), whose tassel ends in a small paper plane (going
abroad). "amar" means "my": the eyes make it a companion, not an agency.

## Files

| File | Use it for |
|---|---|
| `amarabroad-icon.svg` | The main logo: full colour on the blue tile. Site header, social profile pictures, anywhere 48 px and up |
| `amarabroad-icon-small.svg` | Below 48 px (browser tab, tiny avatars): bigger cloud and eyes, no tassel. Also `app/icon.svg` |
| `amarabroad-mark.svg` | One colour, blue, without the tile: on white or light backgrounds |
| `amarabroad-mark-white.svg` | One colour, white: on blue, dark or photo backgrounds |
| `amarabroad-mark-black.svg` | One colour, black: print, stamps, fax-style documents |
| `icon-192.png`, `icon-512.png`, `maskable-512.png` | Phone home-screen icons (used by `app/manifest.ts`) |
| `../favicon.ico`, `app/apple-icon.png`, `app/opengraph-image.png` | Old-browser tab icon, iPhone icon, link preview when the site is shared |

## Name

Write it **amarAbroad**: one word, lower-case "amar", capital "A" for Abroad. On the site the name is set in the
site's font (Geist, bold), "amar" in the text colour and "Abroad" in amar blue.

## Rules

- Clear space: keep at least the width of one eye (about 1/10 of the tile) empty around the logo.
- Smallest sizes: the full icon from 48 px; below that use `amarabroad-icon-small.svg`. One-colour mark from 24 px.
- Don't recolour the cloud, stretch the logo, add shadows or outlines, or put the colour icon on busy photos (use the
  white mark there).
- The drawing is original. Before registering it as a trademark, have a trademark search done.
